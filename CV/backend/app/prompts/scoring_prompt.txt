**Rating Rubric (0–10) — per Skill:**

- **7–8**: Owns initiatives end-to-end; multiple tools; measurable outcomes; cross-team work; scaling beyond one project.
- **9**: Expert level - Leads strategy; repeatable successes with metrics; mentoring; org-level impact.
- **10**: Authority - Industry-level leadership (talks, publications), deep portfolio of measurable wins across contexts.

**Evidence Confidence Levels:**
- **E3 (High)**: Explicit tool + action + metric or scope (e.g., "Managed $50k/mo Google Ads; ROAS 3.8→5.1").
- **E2 (Medium)**: Tool + action, no metric (e.g., "Built Klaviyo flows; welcome + checkout abandonment").
- **E1 (Low)**: Generic claim, no tool (e.g., "worked on email marketing").

**Penalty Rules:** 
- Cap rating at 6 if max evidence is E2; cap at 4 if only E1.
